# ALNS 求解 CVRP：博客配套示例

人工构造的单仓库、12 客户、车辆容量 15、最多 4 辆车的教学实例；使用欧氏距离，目标是总距离最小，不含时间窗或车辆固定成本。不提供全局最优保证。

## 运行

建议 Python 3.10 或更新版本。在项目目录执行：

```bash
python -m pip install -r requirements.txt
python main.py
```

可选参数：

```bash
python main.py --iterations 2000 --seed 42 --output outputs
python verify.py
```

默认输出位置以脚本所在目录为准；指定的相对 `--output` 则以当前工作目录为准。绘图使用无窗口后端，运行后直接保存图片，不弹窗。中文字体优先使用微软雅黑/黑体；其他系统可修改字体设置。

## 内容与输出

- `main.py`：第 5.2～5.9 节代码的完整整合，包含数据、初始解、两个破坏算子、两个修复算子、模拟退火、分段权重更新、主循环与绘图。
- `verify.py`：检查解覆盖与容量、距离增量、算子不修改输入、历史最优单调性和随机种子复现。
- `outputs/routes.png`：初始方案与最好方案对比，可直接用于博客。
- `outputs/convergence.png`：当前解与历史最优目标函数曲线。
- `outputs/weights.png`：两组算子的权重曲线。
- `outputs/result.json`：参数、路径、完整历史及最终权重。
- `outputs/history.csv`：逐轮成本与温度。

算子：随机移除、带随机偏向的最差移除；全局最小增量贪心插入、按不同路径最佳位置计算的 Regret-2 插入。修复失败返回 `None`，当前解保持不变。奖励为 8/4/1/0，初始权重为 1，每 100 轮更新，历史保留比例 0.8，权重下限 0.1。默认移除比例 0.15～0.35，对本例对应每轮移除 1～4 个客户。

该版本保留博客算法规则，对重复的演示调用进行了合并；绘图由 `plt.show()` 改为保存 PNG，并增加命令行、JSON/CSV 导出。项目不包含系统参数对比实验。输出是单次随机搜索结果，相对初始解的改善不等于最优性差距。重新运行同一输出目录会覆盖已有结果。

发布时请保留代码和输出对应的种子、迭代次数及依赖版本。默认结果使用种子 42、2000 轮；验证记录见 `outputs/verification.txt`。
